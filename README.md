# RoadSense 🛣️
### AI-Powered Infrastructure Asset Monitoring & Predictive Maintenance Platform
> *Detect Today. Prevent Tomorrow.* | SDG 9 — Sustainable Infrastructure

## 🚀 Quick Start
```bash
flutter pub get && flutter run
```

## 👥 Roles: Citizen | Engineer | Admin | Decision Maker
## 🤖 AI: Gemini Vision API (8 damage categories, severity, cost estimates)
## 🗺️ Map: flutter_map + OpenStreetMap (50 Bengaluru markers, free)
## 📊 Charts: fl_chart (trend, pie, bar, heatmap)
## 💾 Storage: SharedPreferences (simulated Firebase)
